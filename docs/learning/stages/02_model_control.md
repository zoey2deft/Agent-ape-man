# 阶段 2：模型输出与对话状态

课程编号：10–15  
前置阶段：阶段 1  
阶段目标：控制模型输入输出，并让多轮请求保持正确状态。

## 课程

| 课程 | 文件 | 唯一目标 |
|---|---|---|
| 10 | `lessons/10_multi_turn.py` | 使用响应 ID 或显式历史继续对话 |
| 11 | `lessons/11_structured_output.py` | 使用 Schema/Pydantic 获得结构化结果 |
| 12 | `lessons/12_context_window.py` | 理解上下文、截断和信息丢失 |
| 13 | `lessons/13_token_usage.py` | 读取并解释 token 用量 |
| 14 | `lessons/14_timeout_retry.py` | 为可重试错误实现有上限的退避重试 |
| 15 | `lessons/15_prompt_test.py` | 用固定案例比较 Prompt 行为 |

## 阶段作品

一个支持多轮对话、结构化结果和有限重试的命令行助手。

## 完成标准

- 能解释模型为什么不会自动记住所有历史。
- 能区分自然语言输出和结构化输出的适用场景。
- 能说明哪些错误适合重试，哪些不适合。
- 能查看 token 用量并识别上下文增长。
- 至少有一组固定 Prompt 测试案例。

## 本阶段不学习

不允许模型调用外部函数，不实现自主循环。
