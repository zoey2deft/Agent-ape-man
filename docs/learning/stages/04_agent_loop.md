# 阶段 4：手写 Agent Loop

课程编号：26–31  
前置阶段：阶段 3  
阶段目标：不依赖 Agent 框架，亲自实现能多轮选择工具并可靠停止的循环。

## 课程

| 课程 | 文件 | 唯一目标 |
|---|---|---|
| 26 | `lessons/26_first_agent_loop.py` | 用循环连接模型、工具调用和观察结果 |
| 27 | `lessons/27_stop_rules.py` | 加入最大轮次、完成条件和失败停止条件 |
| 28 | `lessons/28_tool_router.py` | 在多个工具之间进行显式路由 |
| 29 | `lessons/29_short_term_memory.py` | 保存一次任务需要的短期状态 |
| 30 | `lessons/30_plan_and_act.py` | 区分计划信息与实际执行动作 |
| 31 | `lessons/31_agent_loop_test.py` | 测试循环能完成、失败并停止 |

## 阶段作品

一个能选择天气、计算器和本地搜索工具的手写 Agent，带有轮次限制、错误边界和运行记录。

## 完成标准

- 能用伪代码写出 Agent Loop。
- 无论成功或失败，循环都能在有限时间内停止。
- 工具路由不依赖任意代码执行。
- 状态只保存完成任务所需的信息。
- 测试至少覆盖直接回答、一次工具、多次工具和达到上限四种路径。

## 本阶段不学习

不使用 Agents SDK，不构建向量知识库，不接入 MCP。
